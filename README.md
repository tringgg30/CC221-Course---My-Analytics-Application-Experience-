# CC221-Course---My-Analytics-Application-Experience-

3.1. What are the challenges I experienced in doing Exploratory Data Analysis, Inferential Regression Analysis, and Regression for Machine Learning?
- I experienced several challenges while doing Exploratory Data Analysis, Inferential Regression Analysis, and Regression for Machine Learning. In EDA, it was difficult to deal with messy data, decide which variables were important, and choose the right visualizations to understand patterns. For inferential regression, I struggled with checking statistical assumptions and interpreting coefficients, p-values, and the overall meaning of the results. When working with regression for machine learning, I found it challenging to prepare the data correctly, choose the right model, tune hyperparameters, and make sure the model performed well on new data. Despite these challenges, each step helped me understand the data and modeling process better.

3.2 What could have been the reasons why such an event happened?
- The reason this happened is because I was still learning and adjusting to the different steps involved in data analysis. I was working with messy data, unfamiliar variables, and new tools, which naturally made EDA harder. I also didn’t have much experience yet with checking statistical assumptions or interpreting regression results, so inferential analysis felt challenging. When I moved to machine learning, the difficulty increased because I needed to prepare the data properly, choose the right model, and tune it so it wouldn’t overfit. Overall, these challenges occurred simply because I was still developing my skills, and each step required knowledge and practice that I am still building.

3.3. Now what do I need to do better next time?
-Next time, I can do better by improving my approach step by step. First, I need to spend more time understanding the dataset before analyzing it—reading the documentation, checking variable meanings, and cleaning the data carefully. I should also practice using different visualizations so I can choose the right one more confidently during EDA. For inferential regression, I need to review the common statistical assumptions and learn how to check them using diagnostic plots and tests. Strengthening my understanding of coefficients, p-values, and model interpretation will also help. When it comes to machine learning regression, I need to get more comfortable with data preprocessing techniques like scaling, encoding, and handling outliers. It will also help to explore different models, practice tuning hyperparameters, and use tools like cross-validation to check if my model generalizes well. Overall, I just need to keep practicing, studying the methods, and applying them to more datasets so my confidence and skills continue to grow.
